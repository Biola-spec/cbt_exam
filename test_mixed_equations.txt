2. Solve the equation:
2x + 3/4 = 5/2

A. x = (5/2 - 3/4) / 2
   x = (10/4 - 3/4) / 2
   x = 7/4 / 2
   x = 7/8

B. x = (5/2 - 3/4) / 2
   x = (10/4 - 3/4) / 2
   x = 7/4 ÷ 2
   x = 7/8

C. x = (5/2 + 3/4) / 2
   x = (10/4 + 3/4) / 2
   x = 13/4 / 2
   x = 13/8

D. x = (5/2 - 3/4) × 2
   x = (10/4 - 3/4) × 2
   x = 7/4 × 2
   x = 7/2

ANSWER: B
